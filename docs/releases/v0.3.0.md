## What's new

**对话流重做：按回合组织。** 以前一次运行的所有中间过程会一起涌进对话，长任务读起来像日志。现在你说的一句话 → 工作区（推理全文、检索与工具调用、子智能体）→ 永不折叠的答案。运行中逐条展开，落定后收成一行摘要，需要时再展开。

**监督裁决说人话。** 需要你介入时，裁决卡先讲清楚完成了几个任务、哪些卡住、缺哪条证据，再给出每个选项的后果。原始机器原因仍在，但收进了折叠。

**纠偏模式（Correction）。** 新增的运行模式：从一次失败的复现出发，追踪「改了哪些文件 / 验证了什么 / 是否真的好了」。测试要求同一复现场景先失败、后通过，诊断必须覆盖全部改动产物——模型不能自己宣布修好了。

**界面新增繁体中文、日语、俄语。** 三种语言全量翻译。界面文字统一走翻译键，服务端只回错误码，措辞交给前端。

**打开明显更快。** Core 作用域挂载 67.7 s → 2.37 s；桌面窗口不再等后端就绪才显示；首屏入口从 1,695 KB 降到 795 KB（gzip 545 → 269 KB）。

## What's changed

### 新能力

- **平面对话流 v2**：回合结构、工作区折叠、答案永不折叠；审批卡与失败原因始终在折叠外。
- **监督裁决的结构化说明**：任务完成数、阻塞项、缺失证据、修订预算，逐项列出再给选项。
- **纠偏模式**：`correction` 与 Solo / Plan / Review / Spec 等并列，是可持久、可重开的运行模式。
- **三种界面语言**：繁体中文、日语、俄语。i18n 迁移把界面文字全部搬到翻译键。
- **关于页面**按 Agent Teamwork 海报重做。
- **模型控制更细**：reasoning effort 改成滑块；默认模型可从输入框直接切换；每个智能体可单独指定模型。
- **子智能体卡片**并入 agent activity，不再是流外的独立入口。
- **代码字体可选**，字体随包分发，不依赖系统安装。

### 修复

- **网关 SSE 长连接不再被 30 秒空闲切断**。此前任何超过 30 秒的 Core 调用都会被断开；现在按请求关闭空闲超时，由 Core 心跳和客户端看门狗判定死流。
- **OpenRouter 风格的 reasoning 能读到了**。`delta.reasoning` 与结构化 `reasoning_details` 此前被忽略，思考过程没有进入事件日志。
- **存储符号链接检查改为只查作用域内部**。此前从文件系统根一路查到目标，macOS 上 `/var → /private/var` 会让每个作用域都被拒。
- **会话流静默后自动重连**；不再每收到一个事件就重载整个会话。
- **reasoning 滑块写入保持有序且在作用域内**。
- 侧栏多余对话点、残留原生下拉、右栏卡片无法滚动，一并修掉并补全中文。
- 对话总是运行真实模式；任务计划会给出任务名；存储快照会等待忙碌的 SQLite 源。

### 性能

- Core 作用域挂载 **67.7 s → 2.37 s**：三处 N+1 查询收成单次（事件索引改一次读全集，迁移检查按 context 合并）。
- 桌面窗口不再等待后端启动完成，先出界面、后接服务。
- 首屏入口 **1,695 KB → 795 KB**：5 种语言不再静态内联，只加载当前语言。
- 只读目录接口加共享读取缓存（单飞 + 3 s TTL + 写后失效）。

### 升级须知

- **旧工作区会自动拿到新预算**。历史作用域此前停在旧的 65536 / 1048576，本次加入幂等迁移：只升级「仍等于旧出厂默认」的键，你手动改过的值不会被覆盖，每作用域只评估一次。
- 嵌套子智能体放开到二级：Team / Review / Correction 允许协调者的执行者再派发；单个 run 仍在 8 个实例以内。
- 计划步数上限 20 → 64。原先 20 步会把大迁移这类正常任务判成异常。
