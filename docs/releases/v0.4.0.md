## What's new

**登录接上了 Logto，账号归属个人资料。** 桌面端在系统浏览器里完成登录（复用已有 SSO 会话，不用重输密码），会话令牌只留在主进程、不进渲染层。昵称与头像改为写到 Logto 账号，账号中心是唯一出处；未登录时侧栏与个人页只显示「未登录」，不伪装。

**对话流可以换形状了。** 设置 → 常规新增对话流形态：极简只留一行摘要（codex）、逐步一行（claude）、保留最近若干行其余折叠（openchamber）、子智能体行带任务与耗时（trae）、全展开且运行中的子智能体自展开（qoder，默认）。形态决定回合落定后留什么，也决定子智能体一行说多少；运行中与待裁决的回合永不裁剪。

**ArtEx 自主探索模式上线。** 指挥/规划/执行/校验四角色协作的自主探索：运行计划作为账本由全体 worker 共享，worker 结果结算进探索图，trace_search 可以检索一次 run 看过什么、试过什么、被什么拒绝；规划器由运行事实（结算、干预、预算）唤醒，而不是固定节拍。模式与全套 pack 文案支持 zh-CN/zh-TW/en/ja/ru 五语言。

**Mermaid 换成 Pele 渲染。** Markdown 里的图默认走 Pele（按图类型拆包，首张流程图只增量约 61KB gzip）；Pele 拒绝且源码稳定 1 秒后才加载 mermaid 兜底，流式半截围栏不再提前拉整包。配色随主题 CSS 变量，切换明暗与强调色无需重绘。

**侧栏扩到六区块，可以自由排序。** 最近对话、最近活动、所有活动、自由对话、项目分组、项目活动各占一块：齿轮面板里每行可开关、可拖拽排序（Alt+↑/↓ 等价），关掉的块保留槽位。品牌色同时从 teal 换成紫丁香，老装机首次启动自动迁移、自选的强调色不受影响。

## What's changed

### 新能力

- **Logto 登录**：Core 负责 OIDC（ES384 id_token 验证、内存会话、经 Account API 写回昵称/头像）；登录失败、无重启方法的宿主各有针对性指引。
- **推理力度滑块重做**：无级拖拽、松手落定，一次拖过三档只保存一次；最高档紫色星野泛光。命令面板与设置共用同一控件。
- **模式选择器只读本会话的作用域**：修复项目会话被绑到用户作用域的 mode_version、随后 409 mode_unavailable 的问题；已绑错的会话保留绑定并保持报错，重选即可。
- **运行审计可检索**：worker 结果写入探索图（有引用记 finding、无引用记 hint），trace_search 按运行/任务/智能体/自由文本联查事件日志、工具执行与证据归档，密钥自动脱敏。
- **工具结果记录诚实归因**：ok/blocked/error、可否重试、拒绝它的策略与一句 worker 指引，随状态迁移落盘；监督裁决可携带证据引用，开启强制引用后无引用的「满足」立即升级而不是烧修订轮次。
- **冷探索上下文折叠**：每次模型调用前把图里冷的部分折成一条带引用的摘要，原文逐字归档。
- **候选晋升接入评测门禁**：晋升必须携带 eval_run_id 并重算套件/提案/对照/报告哈希，候选决策改为原子状态迁移。
- **界面文案规范**（docs/ui-copy-spec.zh-CN.md）固化「删掉这句话用户会少知道什么」判据。
- **托盘菜单**：关闭主窗口后可保持运行，正在跑的 run 不中断；安装版默认开启，dev 默认关闭。五语言标签。

### 修复

- **本地化 pack 的模式解析不再误报内容篡改**：prompt 版本的内容哈希安装时包含五语言 overlay 字节，解析期校验却只算图本体——只要 pack 带 overlay，会话绑定模式即报 "content hash verification failed"。校验口径已与安装口径对齐。
- **存储锁重试也吃 UnauthorizedAccessException**：Windows 上已存在的锁文件报共享冲突（表现为拒绝访问），此前一次并发挂载就能让拿锁直接失败。
- **投影前先跑挂起的迁移**：协调器先按当前 EF 模型补列会把待迁移正要加的列提前补上，列落地、迁移历史没落，之后每次挂载都撞 duplicate column name。
- **左右列拖动把手骑在缝上**：overflow:hidden 裁掉探出的半边把手后命中区只剩 4px；现在 12px 跨缝、拖动中保持可见。
- **侧栏「新建工作区」按钮只在指针进入工作区块时显现**，且隐形区域不再可点（此前 `.sidebar-extra` 的特异性把隐藏态抹掉了）。
- **行预算折叠噪音不折叠要点**：子智能体行、计划、失败、纠偏与裁决永不进入「N earlier steps」。
- 侧栏页脚昵称按实测宽度显隐，放不下整条收起而不截断；过渡只动透明度，不再切出半截字。

### 性能

- Markdown 首图 **不再拉 mermaid 整包**：pele/lazy 按图类型拆包（flowchart 约 61KB gzip、sequence 约 26KB），mermaid 降为 1 秒延迟兜底。
- 个人页 token 用量改为汇总全部存储作用域（此前只读从不承载项目调用的 user scope）。
- 依赖收尾：dompurify ^3.4.8、monaco 0.56、esbuild 0.28.2（平台二进制与本体版本交叉校验入 CI）。

### 升级须知

- **旧 localStorage 里存的默认强调色 `blue` 会在首次启动时迁移为紫丁香**（`tinadec-accent-migrated-lilac` 一次性标记）；你手动选过的颜色不动。
- **未登录时个人资料的编辑入口变成登录入口**：昵称与头像写入 Logto 账号，本地头像字段是链接不是上传。
- 对话流形态默认 qoder（全展开）；存储值不迁移，未知值回落默认。
- 侧栏旧的四区块记录自愈：缺失区块按声明顺序补在末尾，升级后不会少一块。
